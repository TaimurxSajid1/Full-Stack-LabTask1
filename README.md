✨ Nova Calculator

A modern, visually polished calculator interface built entirely with HTML and CSS.

Nova Calculator focuses on creating a premium calculator UI with glassmorphism, neon gradients, responsive design, subtle animations, and a clean futuristic aesthetic — all without JavaScript.

🌌 Preview

Nova features a dark futuristic interface with:

💎 Glassmorphism calculator card

🌈 Purple and cyan neon accents

✨ Animated hover and click effects

🧊 Frosted-glass background

📱 Fully responsive layout

🎨 Custom calculator buttons

💡 Ambient glowing background orbs

⌨️ Clean and minimal visual hierarchy

⚡ Lightweight and dependency-free structure

🛠️ Built With

HTML5

CSS3

CSS Grid

CSS Flexbox

CSS Animations

CSS Gradients

CSS Backdrop Filters

Responsive Media Queries

No JavaScript is used.

⚠️ Important Note

This project is intentionally built without JavaScript.

Therefore, the calculator currently serves as a frontend/UI design concept rather than a functional calculator.

The buttons and display are designed to demonstrate the visual interface, but mathematical calculations are not processed.

JavaScript would be required to implement functionality such as:

+
−
×
÷
%
AC
Backspace
=
